# M1 – Manuelle Testcheckliste

Auf dem Mac durchgehen, Ergebnisse (✓/✗ + Notiz) direkt hier eintragen oder an Claude melden.

## Vorbereitung

1. `brew install xcodegen`
2. `cp Local.xcconfig.example Local.xcconfig` und die eigene Team ID eintragen
3. `xcodegen generate`
4. `ScreenX.xcodeproj` in Xcode öffnen
5. Scheme `ScreenX` wählen und Run (⌘R)

## Checkliste

- [ ] Erster Start: Die Berechtigungsabfrage erscheint. Nach der Freigabe und einem Neustart der App funktioniert die Aufnahme.
- [ ] Ein erneuter Build aus Xcode mit Personal Team behält die Freigabe.
- [ ] ⌥⇧4: Overlay auf allen Monitoren, Lupe zeigt scharfe Pixel, ⇧ ergibt ein Quadrat, Leertaste verschiebt, Esc bricht ab.
- [ ] Auswahl auf dem Zweitmonitor (falls vorhanden) liefert den richtigen Inhalt, scharf in Retina.
- [ ] ⌥⇧5: Hervorhebung folgt dem Fenster unter der Maus. Die Aufnahme enthält genau das Fenster, mit oder ohne Schatten je nach Einstellung.
- [ ] ⌥⇧3: Vollbild des Monitors mit dem Mauszeiger.
- [ ] Schnellzugriff: Kopieren und Einfügen in Vorschau/Notizen in richtiger Größe. Sichern legt die Datei in `~/Pictures/ScreenX` ab. Drag & Drop in den Finder und in Mail. Anheften verhindert das Ausblenden.
- [ ] Ein Kürzel auf eine belegte Kombination setzen: Die Einstellungen zeigen den Hinweis, die anderen Kürzel funktionieren weiter.
- [ ] Gefühlte Geschwindigkeit: Nach dem Loslassen erscheint die Vorschau ohne merkliche Verzögerung.

## Zusätzlich prüfen (aus den Code-Reviews)

- [ ] Fensteraufnahme MIT Schatten (Einstellungen → „Fensterschatten aufnehmen“): Ist das Bild genauso scharf wie ohne Schatten, und ist es größer als das Fenster selbst? (Verdacht: wird verkleinert/unscharf.)
- [ ] Esc, Leertaste und ⇧ wirken im Bereichs-Overlay, während eine andere App aktiv war.
- [ ] Nach einer Aufnahme behält die vorher aktive App den Tastaturfokus; aufgenommene Fenster sehen „aktiv“ aus (farbige Fensterknöpfe).
- [ ] Die Buttons im Schnellzugriff reagieren auf den ersten Klick, auch wenn ScreenX nicht aktiv ist; Hover zeigt die Aktionen.
- [ ] Nach dem Herausziehen einer Karte, die abgebrochen wurde, blendet sich die Karte trotzdem nach Ablauf der Zeit aus.
- [ ] Schnellzugriff-Karten und das ScreenX-Menü erscheinen nicht in Vollbild- und Bereichsaufnahmen.
- [ ] Tastenkürzel-Aufnahme in den Einstellungen: ⌘-Kombinationen werden erkannt; Einstellungen während der Aufnahme schließen → danach funktionieren die globalen Kürzel wieder.
- [ ] Ein Fehler (z. B. Speicherordner ohne Schreibrecht) erzeugt eine Mitteilung bzw. Meldung.
