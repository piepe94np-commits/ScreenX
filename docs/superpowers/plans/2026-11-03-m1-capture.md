# M1 – Aufnahme: Implementierungsplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Lauffähige Menüleisten-App, die per Tastenkürzel Bereich, Fenster oder Vollbild aufnimmt und das Ergebnis im Schnellzugriff zum Kopieren, Sichern und Herausziehen anbietet.

**Architecture:** Das Xcode-Projekt wird mit XcodeGen erzeugt und besteht aus drei Targets:
- `ScreenXCore` (Framework, enthält alle rechnende und testbare Logik)
- `ScreenXCoreTests` (Tests dafür)
- `ScreenX` (App: Menüleiste, Overlay, Tastenkürzel, Schnellzugriff)

Der Bereichsmodus arbeitet mit einem **Standbild**: Beim Start des Overlays wird jeder Bildschirm einmal aufgenommen und eingefroren angezeigt. Die Auswahl wird dann aus diesem Bild ausgeschnitten. Das ist schnell (keine zweite Aufnahme), liefert die Daten für die Lupe und verhindert, dass das Overlay selbst im Bild landet.

**Tech Stack:** Swift 6, SwiftUI + AppKit, ScreenCaptureKit, Carbon (Hotkeys), ImageIO, Swift Testing, XcodeGen, GitHub Actions (macOS-Runner).

**Spec:** `docs/superpowers/specs/2026-11-03-screenx-design.md`. Für M1 relevant sind Abschnitte 2, 3, 4, 5 („Reiter Export“, nur Dateiname/Format/Ort), 8 und 9.

## Global Constraints

- Deployment Target macOS 26.0. Es werden nur APIs genutzt, die auf macOS 26 verfügbar sind.
- Swift 6 Language Mode, strikte Concurrency. UI-Code ist `@MainActor`.
- Keine externen Abhängigkeiten in der App. XcodeGen ist nur Build-Werkzeug.
- `.xcodeproj` wird nicht eingecheckt (`.gitignore`).
- Bundle-ID `com.screenx.app`, Logger-Subsystem `com.screenx.app`.
- `LSUIElement = YES` (kein Dock-Symbol), keine App-Sandbox.
- UI-Texte auf Deutsch, über `String(localized:)` / String Catalog `Localizable.xcstrings`.
- Signierung: `DEVELOPMENT_TEAM` kommt aus der lokalen, nicht eingecheckten `Local.xcconfig`. Die CI baut mit `CODE_SIGNING_ALLOWED=NO`.
- Standard-Tastenkürzel: Vollbild ⌥⇧3, Bereich ⌥⇧4, Fenster ⌥⇧5.
- Schnellzugriff verschwindet nach 6 s (einstellbar), Standard-Speicherort `~/Pictures/ScreenX`.
- Dateiname: `ScreenX JJJJ-MM-TT um HH.MM.SS.png` (bzw. `.jpg`).
- Alle neuen Typen in `ScreenXCore` sind `public`, `Sendable` wo möglich, und haben Tests in `ScreenXCoreTests`.

**Verifikation (gilt für alle Tasks):**
- **Auf dem Mac:**
  ```
  xcodegen generate && xcodebuild test -project ScreenX.xcodeproj -scheme ScreenXCore -destination 'platform=macOS'
  ```
- **In der Cloud-Sitzung:** pushen, dann den Lauf des Workflows `CI` über die GitHub-MCP-Tools (`actions_list` / `get_job_logs`) prüfen.

„PASS“ bedeutet in beiden Fällen: Job grün, und die genannten Tests stehen im Log als bestanden.

## Review Focus

1. **Mehrere Monitore mit unterschiedlicher Skalierung und Anordnung:** Ein Zweitmonitor links oder oberhalb des Hauptmonitors hat negative globale Koordinaten. Die Auswahl muss trotzdem exakt die gewählten Pixel liefern. → Tests in Task 3 (`CoordinateSpace`, `SelectionGeometry.pixelRect`).
2. **Auswahl über zwei Monitore gezogen:** Die Auswahl wird auf den Monitor begrenzt, auf dem das Ziehen begann. Es gibt kein leeres oder verzerrtes Bild. → Test `clampsToStartDisplay` (Task 3).
3. **Klick ohne Ziehen oder Mini-Auswahl unter 4 pt:** Das gilt als Abbruch, nicht als 0×0-Bild. → Test `tinySelectionIsInvalid` (Task 3).
4. **Zwei Aufnahmen in derselben Sekunde, oder der Zielordner fehlt:** Der Ordner wird angelegt, der zweite Dateiname bekommt den Zusatz ` (2)`. Nichts wird überschrieben. → Tests `createsMissingDirectory`, `doesNotOverwrite` (Task 2).
5. **Tastenkürzel bereits von einer anderen App belegt:** Die übrigen Kürzel funktionieren weiter. Die Einstellungen zeigen genau dieses Kürzel als belegt an. → Test `mapsHotkeyExistsError` (Task 5).
