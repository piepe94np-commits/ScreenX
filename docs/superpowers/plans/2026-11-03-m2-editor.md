# M2 – Editor und Verschönern: Implementierungsplan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ein Editor-Fenster, in dem eine Aufnahme mit Hintergrund, Abstand, Ecken, Schatten und Format verschönert, als Bild exportiert und als `.screenx`-Projekt gespeichert bzw. wieder geöffnet werden kann.

**Architecture:**
- Alles Rechnende liegt in `ScreenXCore` und ist auf der CI testbar: Stil-Modell, Layout, Renderer, Dokument und Paketformat.
- Die App bekommt ein Editor-Fenster (SwiftUI in einem `NSWindowController`) mit einem `@Observable`-ViewModel. Es hält das Dokument und rendert die Vorschau über denselben `Renderer` wie der Export.
- Undo läuft über den `UndoManager` des Fensters und speichert Schnappschüsse des Modells.

**Tech Stack:** Swift 6, SwiftUI + AppKit, Core Graphics, Core Image, `FileWrapper`, Swift Testing.

**Spec:** `docs/superpowers/specs/2026-11-03-screenx-design.md`. Für M2 relevant sind Abschnitt 5 (komplett) sowie die Abschnitte 4 (Menüleiste), 6 (Undo für Stil), 8 und 9.

## Global Constraints

- Gilt alles aus `docs/superpowers/plans/2026-11-03-m1-capture.md` → „Global Constraints“: macOS 26, Swift 6, keine Abhängigkeiten, deutsche UI-Texte im String Catalog, CI-Verifikation.
- Stil-Standardwerte:
  - Hintergrund: Verlauf, Vorlage 1
  - Abstand 64, Eckenradius 12, Schatten 50
  - Fensterschatten behalten: nein
  - Format Auto, Position Mitte
- Wertebereiche:
  - Abstand 0–400 px
  - Ecken 0–60 px
  - Schatten 0–100; ausklappbare Detailregler für Versatz Y, Weichheit und Deckkraft
  - Formate: Auto, 16:9, 4:3, 1:1, 9:16, 3:2
  - Position: 9-Punkt-Ausrichtung
- Alle Pixelwerte (Abstand, Radius, Schatten) beziehen sich auf die **Pixel des Originals**.
- Export:
  - PNG (Standard) oder JPEG (Qualität 0–100, Standard 90)
  - Skalierung „Original“ (Standard), 1× oder 2×
  - Speicherort `~/Pictures/ScreenX`
  - Dateiname wie in M1
- Projektformat `.screenx`:
  - Paket mit `document.json`, `original.png`, optional `background.<ext>`, `preview.png` (max. 1024 px)
  - UTI `com.screenx.document`, konform zu `com.apple.package`
  - Feldnamen von `document.json` exakt wie in Spec §5
- Tastenkürzel im Editor:
  - ⌘C kopiert das gerenderte Bild
  - „Sichern“ exportiert in den Speicherort
  - ⇧⌘S öffnet „Sichern unter …“ (Export mit Dialog)
  - ⌘S speichert das Projekt
  - ⌘O öffnet ein Projekt
  - ⌘Z / ⇧⌘Z: Rückgängig / Wiederholen
- Fehlerfälle nach Spec §8:
  - beschädigtes Paket: Meldung, Datei bleibt unverändert
  - höhere `version`: nur ansehen, mit Hinweis
  - Speichern fehlgeschlagen: Meldung, das Dokument bleibt offen
- `.superpowers/` wird nie committet.

## Review Focus

1. **Alte Einstellungen nach dem Update:** Gespeicherte `settings.v1` aus M1 haben die neuen Felder noch nicht. Die bisherigen Werte des Nutzers müssen erhalten bleiben, statt auf die Standardwerte zurückzufallen. → Test `decodesM1SettingsWithoutNewFields` (Task 5).
2. **Sehr große Aufnahmen (z. B. 6016×3384 auf einem 6K-Display) und Schieberegler:** Die Vorschau darf nicht ruckeln, und der Export behält die volle Auflösung. → Renderer-Parameter `outputScale` (Task 3) plus eine Vorschau, die nur in Anzeigegröße rendert (Task 6).
3. **Format mit Seitenverhältnis bei Abstand 0:** Der Rahmen wird nur erweitert, nie beschnitten. Die Aufnahme bleibt vollständig sichtbar. → Tests `aspectExpandsNeverCrops` (Task 2).
4. **Transparenter Hintergrund und JPEG-Export:** JPEG hat keinen Alphakanal. Transparente Bereiche werden weiß statt schwarz. → Test `jpegFlattensTransparencyOnWhite` (Task 3).
5. **Projekt mit eigenem Hintergrundbild verschieben oder kopieren:** Das Bild liegt im Paket, nicht als Verweis auf eine externe Datei. Nach dem erneuten Öffnen ist es da. → Test `roundTripWithBackgroundImage` (Task 4).

**Files:**

**Interfaces:**
- Consumes: `Style`, `Background`, `CanvasLayout`, `ShadowStyle.resolved()`, `ImageCropper`
- Produces:
  - `public struct RenderInput: Sendable { public var original: CGImage; public var crop: CGRect?; public var style: Style; public var backgroundImage: CGImage?; public init(...) }`. `crop` in Pixeln, Ursprung oben links.
  - `public enum Renderer { static func render(_ input: RenderInput, outputScale: CGFloat = 1) -> CGImage? }`
    - Ausgabegröße = `canvasSize × outputScale`, gerundet
    - sRGB, premultiplied, mit Alphakanal
    - Ursprung oben links: Kontext mit Spiegelung
  - Reihenfolge beim Zeichnen:
    1. Hintergrund
    2. Schatten: gefülltes Rundrechteck mit `setShadow`, Versatz y nach unten, Farbe Schwarz mit Deckkraft

    4. Bild bzw. Zuschnitt
  - Hintergrund-Typen:
    - **Verlauf:** linear, Winkel wie CSS. 135° = von oben links nach unten rechts, 0° = von unten nach oben, 90° = von links nach rechts.

    - **Bild:** füllt den Rahmen (aspect-fill).
    - **Unscharfer Screenshot:** `CIGaussianBlur` (radius × outputScale) auf dem Original, gestreckt auf den Rahmen, Ränder mit `clampedToExtent`.
    - **Keiner:** transparent.
  - `ImageExporter.data(..., format: .jpeg)`: zeichnet vor dem Kodieren auf eine weiße, deckende Fläche.
